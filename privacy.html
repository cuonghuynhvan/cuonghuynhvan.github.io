Privacy Policy – Channel Publisher

Last updated: October 12, 2026

Channel Publisher is a personal tool operated by Cuong Huynh Van to publish videos to YouTube channels and Facebook Pages he owns. It is not available to other users.

Data we access

With the owner's authorization, the tool uses Google OAuth to access the owner's YouTube account (scopes youtube.upload and youtube.force-ssl) in order to upload videos, set metadata, thumbnails and playlists, and read basic channel and video information.

How data is used and stored

Access tokens are stored only on the owner's own computer. No data is sold, shared with third parties, or used for advertising. Data is used only to perform the publishing actions requested by the owner.

Channel Publisher's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Locally stored tokens can be deleted by removing them from the owner's computer.
